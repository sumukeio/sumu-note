# ADR — 思维笔记（mind_notes）计划下线

> **状态**：[已决策 / 待实施]  
> **日期**：2026-09-16  
> **决策人**：产品负责人（用户确认）

## Context

思维笔记长期投入但体验与完成度未达预期；同时普通笔记缺陷积压（发布、删除、移动、统计等）。继续双线并行会稀释修复带宽。

## Decision

**思维笔记计划下线。**

本期（本 phase）仅锁定决策与范围，**不实施**下线代码。实施必须另开 phase，并分步：

1. **冻结**：不再接受 mind_notes 新功能需求（Bug 仅安全/数据丢失级才修）。
2. **隐藏入口**：导航/Dashboard 入口下线或标「即将移除」（实施 phase）。
3. **数据**：默认保留云端表数据，提供导出或只读打开窗口（实施前再定）。
4. **清理**：确认无用户依赖后再考虑 schema/代码移除（最后一步）。

## Alternatives

| 方案 | 为何不选（当前） |
| :--- | :--- |
| 继续打磨思维笔记 | 与用户判断不符；占用修普通笔记 P0 的带宽 |
| 立即删除代码与表 | 不可逆；违反「优雅归档」与数据安全 |
| 仅归档文档仍开放入口 | 「计划下线」信号不清，用户继续产生依赖 |

## Consequences

- 新 issue/task 默认**不**排思维笔记体验类需求。
- 普通笔记 P0（删文件夹、发布、统计等）优先。
- 相关文档应加状态标识「计划下线」，禁止硬删历史 PRD/任务文档。

## Rollback

若撤回下线决策：将本 ADR 文首改为「已废止」，并开新 ADR 说明恢复维护。
